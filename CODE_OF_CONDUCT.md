# Code of Conduct

Please keep this project respectful, constructive, and welcoming.

## Expected Behavior

- Be kind and professional
- Discuss ideas with curiosity and evidence
- Offer actionable feedback
- Respect different experience levels

## Unacceptable Behavior

- Harassment or personal attacks
- Abusive or discriminatory language
- Deliberate disruption or spam

If you encounter unacceptable behavior, report it privately to `alokgarg003@gmail.com`.
